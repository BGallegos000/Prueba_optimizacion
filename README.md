# Prueba Optimización: Organización del Repositorio

Este repositorio está ahora organizado en dos carpetas principales para separar claramente la entrega final del material de estudio.

## Estructura del proyecto

- `entrega/` — Archivos requeridos para la evaluación y entrega final.
- `estudio/` — Documentación de apoyo y análisis profundo del Algoritmo Genético.

## Uso recomendado

- Abre `entrega/README.md` para preparar la entrega y revisar el código final.
- Abre `estudio/README.md` para consultar la documentación pedagógica y justificar la elección del método.

## Contenidos

### Carpeta `entrega`
- `knapsack_genetic_algorithm.py` — Implementación principal del Algoritmo Genético.
- `ejemplos_uso.py` — Ejemplos prácticos para ejecutar y probar el algoritmo.
- `analisis_comparativo.py` — Comparación con Simulated Annealing y Tabu Search.
- `METODOLOGIA_GENETICO.md` — Documentación técnica de la metodología utilizada.
- `ENTREGA_FINAL.md` — Resumen ejecutivo pensado para la evaluación.
- `ip_mejorada.py` — Implementación de Branch & Bound de referencia.
- `README.md` — Guía de esta carpeta de entrega.

### Carpeta `estudio`
- `01_ANALISIS_POR_QUE_GA_DESTACA.md` — Por qué GA es superior frente a otras metaheurísticas.
- `02_EXPLICACION_CODIGO_LINEA_POR_LINEA.md` — Explicación detallada del código del GA.
- `03_PUNTOS_CLAVE_GA_DEFINICIONES.md` — Definiciones clave y conceptos esenciales del GA.
- `04_CONTEXTO_HISTORICO_GA_DOMINA.md` — Historia y contexto académico del dominio del GA.
- `INDICE_DOCUMENTACION_PEDAGOGICA.md` — Guía de lectura para los documentos de estudio.
- `GA_QUICK_REFERENCE.md` — Resumen rápido con los puntos más importantes.

## Cómo empezar

1. Instala dependencias:
   ```bash
   pip install numpy
   ```
2. Revisa `entrega/README.md` para ejecutar el proyecto de evaluación.
3. Revisa `estudio/README.md` para profundizar en la teoría y los análisis.
