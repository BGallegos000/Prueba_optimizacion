# Entrega de Evaluación

Esta carpeta contiene los archivos requeridos para la entrega final de la evaluación.

## Contenido

- `knapsack_genetic_algorithm.py` — Implementación principal del Algoritmo Genético para el problema 0-1 Knapsack.
- `ejemplos_uso.py` — Ejemplos prácticos de uso y pruebas básicas del algoritmo.
- `analisis_comparativo.py` — Comparativa con otros métodos como Simulated Annealing y Tabu Search.
- `METODOLOGIA_GENETICO.md` — Documentación técnica y metodología utilizada para el algoritmo genético.
- `ENTREGA_FINAL.md` — Resumen ejecutivo y propuesta de entrega para la evaluación.
- `ip_mejorada.py` — Implementación de Branch & Bound usada como referencia comparativa.
- `README.md` — Documentación principal de la solución dentro de la carpeta de entrega.

## Cómo usar

1. Instala dependencias:
   ```bash
   pip install numpy
   ```
2. Ejecuta el archivo principal:
   ```bash
   python knapsack_genetic_algorithm.py
   ```
3. Revisa los ejemplos en `ejemplos_uso.py` y el análisis en `analisis_comparativo.py`.
