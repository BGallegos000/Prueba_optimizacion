# Estudio del Método Genético

Esta carpeta contiene la documentación de apoyo y los archivos de estudio sobre por qué el Algoritmo Genético es el método seleccionado y qué lo hace superior frente a otras metaheurísticas.

## Contenido

- `01_ANALISIS_POR_QUE_GA_DESTACA.md` — Análisis comparativo detallado con otros métodos.
- `02_EXPLICACION_CODIGO_LINEA_POR_LINEA.md` — Explicación línea por línea del algoritmo y las decisiones de diseño.
- `03_PUNTOS_CLAVE_GA_DEFINICIONES.md` — Definiciones clave del algoritmo genético.
- `04_CONTEXTO_HISTORICO_GA_DOMINA.md` — Contexto histórico y académico de la dominancia del GA.
- `INDICE_DOCUMENTACION_PEDAGOGICA.md` — Guía de lectura para los documentos de estudio.
- `GA_QUICK_REFERENCE.md` — Resumen rápido con los puntos más importantes.

## Uso recomendado

- Lee primero `INDICE_DOCUMENTACION_PEDAGOGICA.md` para elegir el mejor documento según tu objetivo.
- Usa `02_EXPLICACION_CODIGO_LINEA_POR_LINEA.md` para entender el código en detalle.
- Usa `01_ANALISIS_POR_QUE_GA_DESTACA.md` para justificar la elección del GA frente a otros métodos.
